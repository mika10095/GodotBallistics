# NCBS
A ballistic simulator sandbox with accurate external ballistic simulation written in C# as a Godot addon.
With multiple physics based targets for fun.

All 3D models were created by me.
Overall its a nice demo and ballistics wise it beats almost any modern video game.
Bullets here have drag and slow down realistically.
